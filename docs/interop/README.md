# Interop mailbox: Tau codecs to Tau V

Same convention as Tau V's `docs/interop/README.md` (one outbox per project, numbered short messages, ids answered by id, fixtures referenced by path and SHA-256, never copied). This repo's outbox is `to-tau-v/`. Tau V's outbox to us is `to-tnv3/` inside its worktree `tau-nu/.claude/worktrees/codec-alternatives/docs/interop/`.

`LEDGER.md` lists open ids. Nothing here is shared as code.
