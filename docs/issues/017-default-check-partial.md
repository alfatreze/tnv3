# 017 — Default checker cannot claim complete conformance

2026-11-07. The Omega CLI contract expects `check FILE --json` to cover every container rule and uses exit 0 for a valid result. The existing `container-preview` scope is intentionally partial and does not validate TVC/TAC payloads; it also stops at the first finding. An isolated prototype in `work/cli-check-finish` defaulted the unqualified command to that scope and returned 0 for `VALID`, while disclosing incomplete coverage in JSON. **Host:** its CLI suite passed, but a consumer relying on the contractual exit status could mistake partial success for full conformance. The prototype remains isolated. Safe workaround: require `--scope` and check the declared coverage; do not use it as a full validator. Next step: implement and validate the remaining full-checker requirements before enabling an unqualified success result, or agree an explicitly different contract with the consumer.
