# 018 — C tool versions are not exposed

2026-11-07. Omega expects a version/compatibility handshake. The current `tvc_enc` and `tnv3` sources do not define tool semantic versions; invoking their current binaries with `--version` returned usage and failure. TNV3's format version is not a tool version. FFmpeg/FFprobe provide `-version`, but the CLI does not yet safely probe selected executables or bind the result to later execution. **Host:** the version investigation in `work/cli-tool-versions` used local tools; versions of other builds remain unknown. The scoped handshake reports explicit-file hashes and does not claim semantic compatibility. Next: define maintained source tool version/build identity, provide explicit C tool version endpoints, then implement bounded platform-specific selected-tool probing and compatibility rules, with failure and path-change tests.
